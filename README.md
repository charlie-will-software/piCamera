# piCamera

## Stream Raspberry Pi 5 camera to http endpoint

Made with Python for Raspberry Pi 5

[![Code style: black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)

## Introduction

PiCamera is a webapp using the Picamera2 library and flask.
From this we yield a http website outputting the camera feed.

## Running The Webapp

1. Configure the "configuration.yaml" file
2. Run webapp/main.py
